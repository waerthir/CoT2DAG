我们接下来要写一个脚本放在scripts下面，脚本关注这些内容

输入是一个大json，像是这样子
[
  {
    xx: xx,
    ...
    "reasoning_chain_model": xx,
    ...
  },
  ...
]

输出是一个json，像是这样子
[
  {
    "batch_id": xx,
    "reasoning_chain_model": xx
  },
  ...
]

其中我们会指定一个抽取数量。我们期望从原文件中随机抽取指定抽取数量的元素，抽取完之后我们会按照顺序给编号，例如001，002...这取决于抽取数量的位数。如果抽取数量过多，则取到源文件上限即可。

输入和输出都应该被指定不应该硬编码写死，应该可以指定参数。这里可以考虑命令行，也可以考虑配置文件。但是考虑脚本的轻量化特性，命令行似乎是更好的选择？但是我也不是非常确定
