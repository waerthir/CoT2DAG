# Batch ID 独立化计划

- 新建 `scripts/make_batch_ids_unique.py`，使用两个命令行位置参数指定输入 JSON 路径与输出 JSON 路径。
- 读取顶层为列表的输入 JSON；每个元素必须是对象，且包含非空字符串 `batch_id`。
- 按输入原始顺序，将每条记录的 `batch_id` 改为 `<原 batch_id>__row_<六位一基序号>`，例如 `open_xxx__row_000001`。
- 保留完整元素及其余所有字段，仅改写 `batch_id`；输出保持原始列表顺序。
- 在终端输出处理记录数和输出路径。
- 输入文件不存在、不是合法 JSON、顶层不是列表、元素或 `batch_id` 不符合要求，或输出路径与输入路径相同时，在终端报错结束。
