# SSH 目录下载器计划

- 新建 `scripts/download_ssh_directory.py`，使用 Paramiko 通过现有 SSH 配置中的 `xAILab-public` 建立 SFTP 连接。
- 命令行只接收两个位置参数：远程源目录和本地下载目录。

  ```powershell
  python scripts\download_ssh_directory.py <远程源目录> <本地下载目录>
  ```

- 递归遍历远程源目录，将其中的目录层级和文件镜像到本地下载目录。
- 下载前读取远端文件大小；本地同名文件存在且大小一致时跳过，文件不存在或大小不一致时下载。
- 每个文件先下载为同目录 `.part` 临时文件；临时文件大小与远端一致后，替换为正式文件。
- 连接、目录遍历、文件下载和远端大小读取通过 Tenacity 重试；连接断开时重新建立 SFTP 连接并继续处理。
- 单个文件最终失败时在终端输出其远程路径和错误；其余文件继续下载。
- 结束时输出目录数、文件总数、已跳过数、下载成功数和失败数；再次运行同一命令时继续补齐未完成文件。
