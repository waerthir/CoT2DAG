# 评分结果统计与绘图计划

## 新增脚本

- 新建 `scripts/analyze_evaluation_scores.py`，从评分结果 JSON 中提取指定的 `evaluation` 字段，生成统计文本和汇总分布图。

## 命令行参数

- 接收输入评分表路径、文本报告输出路径、图片输出路径。
- 接收 `--threshold <浮点数>`；分数大于或等于该阈值时计为合格。
- 接收 `--metrics <JSON 对象>`；对象的键为 `evaluation` 内待统计的字段名，值为报告和图表显示的中文名称。例如：

  ```text
  --metrics '{\"Fidelity\":\"信息忠实度\",\"Atomicity\":\"原子化程度\"}'
  ```

- 节点评分与关系评分均使用同一脚本，仅替换输入文件、阈值和 `--metrics` 参数。

## 数据处理与统计

- 读取根节点为列表的评分 JSON，逐项读取 `evaluation` 对象中的指定指标并转换为浮点数。
- 每个指标独立统计实际获得的分数；其总数量作为该指标合格率的分母。
- 按旧脚本口径计算均值和总体方差：`sum((score - mean)^2) / n`。
- 以 `score >= threshold` 统计每个指标的合格数量、总数量和合格率。
- 当输入 JSON、`--metrics` 字典、`evaluation` 字段或分数值不符合要求时，以清晰错误信息结束；指定指标没有任何有效分数时不生成结果。

## 文本报告

- 创建指定输出路径的父目录，并写入 UTF-8 文本报告。
- 报告记录输入文件、合格阈值，以及每个指标的中文名称、原始字段名、均值、总体方差、合格数量、总数量、合格率。

## 汇总图

- 使用 Matplotlib 与 Seaborn 生成一张汇总 PNG；每个选定指标占一个子图。
- 每个子图绘制 0–10 分的直方图与 KDE 曲线，横轴显示分数，纵轴显示频数。
- 在每个子图中绘制阈值竖线，并在标题中展示中文指标名和 `合格数/总数（合格率）`。
- 使用可显示中文的字体回退配置，隐藏汇总画布中未使用的子图区域。

## 验收

- 对节点评分表传入 `Fidelity`、`Atomicity` 能输出两项统计结果和两张子图。
- 对关系评分表传入四个关系指标能输出四项统计结果和四张子图。
- 文本中的均值、总体方差、合格数量、总数量和合格率与输入分数及阈值一致。
- 图表标题使用 `--metrics` 指定的中文名称，并显示相同的合格统计。
