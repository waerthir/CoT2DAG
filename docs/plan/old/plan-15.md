# 指定字段中文比例检测与剔除计划

- 在 `scripts/check_json_chinese.py` 增加 `--field <字段名>`，对顶层列表中每个对象的指定字符串字段进行检测。
- 增加 `--han-ratio-threshold <0-100>`；中文比例按“字段内汉字数 / 非空白字符数 × 100”计算，严格超过阈值时判定该元素为中文项。
- 指定字段模式继续使用 `--min-consecutive-han`；元素需同时满足连续汉字阈值和中文比例阈值才报告。
- 每个命中元素在终端输出元素索引、字段名、首个连续汉字段、连续长度和中文比例；完成后输出命中数量、总元素数量。
- 增加 `--remove-chinese`；启用时从顶层列表移除全部中文项对应的完整元素，不修改保留元素中的任何字段。
- 增加 `--filtered-output-json <路径>`；`--remove-chinese` 启用时必填，按原顺序将未命中元素写为 JSON 数组，禁止覆盖输入文件。
- `--remove-chinese` 与输出路径仅适用于顶层列表和 `--field` 指定字段模式；参数组合不完整或阈值不在 0–100 时在终端报错结束。
